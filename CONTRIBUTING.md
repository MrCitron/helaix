# Contributing to HelAIx

First off, thank you for considering contributing to HelAIx! We appreciate your time and effort to improve this project.

## How to Contribute

### 1. Reporting Bugs
If you find a bug, please open an issue and include:
- A clear and descriptive title.
- Your operating system and version.
- Your Helix hardware and firmware version.
- Steps to reproduce the issue.
- Expected behavior vs actual behavior.

### 2. Pull Requests
I actively welcome your pull requests. Please follow these steps:

1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add unit tests where applicable.
3. If you've changed UI or workflows, please test thoroughly on your machine.
4. Ensure your code respects the existing formatting and style guidelines of the Go and React codebases.
5. Submit a PR!

**Important:** When submitting a PR, please ensure you fill out the provided Pull Request template completely. It is crucial for reviewers to understand:
- A clear description of the functions added or bugs fixed.
- The tests that were performed.
- The OS and specific Line 6 Helix hardware used for testing, as hardware compatibility is a key part of this project.

## Development Setup
Please refer to the `README.md` and `docs/` or `specs/` directories for detailed instructions on the architecture and how to set up the Go/Wails/React development environment.
